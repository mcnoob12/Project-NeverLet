# KalTex

KalTex is a radically open, paper-first preprint platform for independent researchers. It gives researchers a public research home, a discovery feed where papers are the posts, clear publishing status, durable versions, and a growing citation graph.

Start with these documents:

- [Platform brief](platform.md): mission, scope, experience, trust model, and V1 decisions.
- [Architecture](docs/architecture.md): serverless Cloudflare/MongoDB/R2 design, costs, and operating boundaries.
- [System design](docs/system-design.md): exact implementation boundaries, authentication, data model, state machines, APIs, security, recovery, and rollout spikes.
- [Agent guide](AGENTS.md): rules for anyone building or evaluating the repository.

The product is self-funded by Kalaris Labs as a community initiative. It welcomes every researcher while putting independent researchers first.
